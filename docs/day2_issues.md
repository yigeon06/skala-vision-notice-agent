# 2일차 문제 기록

2026-10-21 — 이후 발생하는 문제는 이 문서에 번호를 이어서 추가한다.

## 1. 2일차 목표와 검색 구조

- 공지·일정 질문을 SQL 조건 검색과 벡터/RAG 의미 검색으로 처리한다.
- 답변을 뒷받침하는 공지만 출처로 표시한다.

## 2. 근거가 없는 공지가 검색 결과로 표시되는 문제

- 질문: “항공회사 지원 시 필요한 자격증은 어떤 게 필요해?”
- 자격증 정보가 없는 `Procurement 경력사원 채용`이 유사도 0.491로 반환됐다.
- 답변은 “확인할 수 없다”고 하면서 관련 없는 출처 카드를 표시했다.

## 3. 원인

- 벡터 검색은 정답 유무와 관계없이 가까운 상위 청크를 반환한다.
- 기존 RAG는 답변 근거 확인 없이 상위 공지를 출처로 사용했다.
- 유사도 점수만으로 답변 가능 여부를 판단하지 않았다.

## 4. 해결 과정

- RAG 응답을 `supported`, `answer`, `source_notice_ids` Structured Outputs로 변경했다.
- 질문의 조건이 공지에 명시된 경우만 `supported=true`로 처리하고, 실제 답변에 사용한 공지만 출처로 반환한다.
- 근거가 없으면 고정 안내를 표시하고 출처를 비운다.

## 5. 검증 방법

- 관련 공지가 있는 질문, 없는 질문, 모델이 존재하지 않는 공지 ID를 반환하는 경우를 확인한다.
- 테스트 코드는 작성했으며, 사용자는 아직 실행하지 않았다.

## 6. 남은 한계

- 의미 질문이 조건 없는 SQL 검색으로 잘못 분류될 수 있다. 이번 수정에는 분류 로직 변경을 포함하지 않았다.
- 실제 질문 평가 후 유사도 임계값을 검토해야 한다.
